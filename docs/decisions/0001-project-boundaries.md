# ADR 0001 Separate tax project and delivery boundaries

**Status: accepted for repository foundation, 21 October 2026.** The owner authorised a new repository and full staged SDLC, and confirmed the bounded employee profile, 2025, evidence-backed review packet and two deduction research candidates.

Keep this project separate from invoice reconciliation. Transfer relevant context and tested engineering patterns, while independently reviewing tax data, rules and application interfaces. Existing software tests or model results remain invoice evidence.

Make discovery decisions, implementation and release evidence inspectable in one repository. Application inference starts disabled with zero allowance; AWS development/staging/production remain unprovisioned. No prior experiment or cloud budget target authorises new inference or deployment here.
