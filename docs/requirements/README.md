# Requirements and traceability

The [requirements register](requirements.json) contains draft functional and quality requirements derived from the selected product boundary. Owner answers live in [discovery](../product/discovery.md). A requirement is accepted only when its meaning and verification fit the agreed scope; its existence does not prove implementation.

For each vertical slice, link requirement IDs to code/tests, evaluation cases, independent review and owner acceptance. Retain planned versus actual evidence. The [backlog](../product/backlog.md) declares prerequisites; the [SDLC](../process/sdlc.md) defines stage exit evidence.
