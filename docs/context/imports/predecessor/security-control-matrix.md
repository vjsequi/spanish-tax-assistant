# Security controls and verification matrix

**Version 1, 17 October 2026. Scope: implemented local application and planned cloud boundaries.** The protected assets are workspace evidence, financial authority/history, credentials, provider allowance and usable diagnostic records. Untrusted boundaries include user/HTTP input, PDF/CSV bytes, extracted evidence, model output, queue deliveries and telemetry exporters.

The matrix links controls to current test definitions and the 17 October regression receipt (previous repository: `../evaluation-results/2026-10-17-reviewed-summary.md`). That receipt records 590 passing backend tests, including 145 PostgreSQL integration tests, and 15 frontend tests at the SEC-01 milestone. New comparison-source checks are separately recorded in the dated backlog. Links identify evidence and reproduction targets, not proof of cloud execution or a security certification.

## Local threats and controls

| Threat or failure | Implemented control and linked tests | Residual risk and next evidence |
|---|---|---|
| Direct prompt injection in a customer note | Untrusted evidence cannot grant tools/authority; closed output schema and scoped snapshots. Contract tests (previous repository: `../../tests/unit/test_investigation_contracts.py`): `test_unknown_fields_cannot_add_tools_scope_or_external_evidence`, `test_schema_has_closed_objects_and_no_approval_action`. Role tests (previous repository: `../../tests/integration/test_isolation_recovery.py`): `test_worker_can_propose_but_cannot_approve_or_reverse`. | A model can still produce an unsupported interpretation; independent exact checks and actual semantic review are required. No blanket injection-resistance claim. |
| Indirect instructions extracted from a document | Intake retains original/extraction provenance; extracted text becomes bounded evidence, not higher-priority authority. Intake journey (previous repository: `../../tests/integration/test_intake.py`): `test_imported_facts_use_shared_investigation_approval_and_reversal`; same investigation validators apply. | Current attack examples mainly cover text notes. Add malicious text-PDF → reviewed intake → investigation trials; extracted text is not a trusted instruction. OCR is unsupported. |
| Attempted override, secret request or approval instruction goes unnoticed | SEC-01 scans bounded sources before inference, commits immutable source/run-bound findings and renders advisory warnings. Signal tests (previous repository: `../../tests/unit/test_security_signals.py`); persistence tests (previous repository: `../../tests/integration/test_security_signals.py`): `test_real_rules_warning_persists_before_result_and_replay_does_not_duplicate`, `test_sql_rejects_forged_signal_metadata`. | Pattern checks can miss obfuscation/indirection; legitimate quotes can trigger them. An alert is suspicion, not confirmed intent or evidence of a successful breach. New runs can flag the same note again. |
| Reporting failure or replay erases a finding | Store-before-inference, immutable records, source/lease/current-membership fences, same-run idempotency. Signal persistence tests (previous repository: `../../tests/integration/test_security_signals.py`): `test_new_evidence_requires_a_fresh_assessment`, `test_security_recording_failure_prevents_inference_and_keeps_balances`, `test_model_path_keeps_finding_even_when_telemetry_fails`. | Diagnostic export is best effort and can be lost after commit. No exactly-once monitoring promise. Old recordings truthfully lack a captured assessment. Retention follows run history; no automatic purge is implemented. |
| Cross-workspace read/write or forged source ownership | Current membership, scoped reader/tools, RLS and composite foreign keys. Isolation tests (previous repository: `../../tests/integration/test_isolation_recovery.py`): `test_foreign_proposal_and_evidence_are_rejected`, `test_membership_checked_even_if_workspace_context_is_forged`; signal fences (previous repository: `../../tests/integration/test_security_signals.py`): `test_reporting_preserves_lease_and_tenant_boundaries`. | Verify identity mapping, IAM, storage and negative access again in each deployed environment. A note's claim of a foreign invoice is not an actual access test. |
| Fabricated citations, amounts, unsupported intent or scope expansion | Exact cents, closed schema, quote/hash/source checks and independent scorer. Investigation contracts (previous repository: `../../tests/unit/test_investigation_contracts.py`): `test_rejects_invalid_scope_evidence_and_balances`, `test_hash_changes_reject_all_outcomes_not_only_cited_proposals`; scorer tests (previous repository: `../../tests/unit/test_evaluation_scoring.py`): `test_citation_linkage_not_merely_presence`, `test_human_can_reject_semantic_support_of_exact_answer`. | Mechanical citation identity does not prove intent. Every conclusion/claim/question needs a real human judgement, retained against its trial hash. |
| Stale or duplicate financial command; concurrent overallocation | Transactional exact reviewed digest, snapshot/version checks, command idempotency, row locking and append-only reversal. Ledger tests (previous repository: `../../tests/integration/test_ledger.py`): `test_competing_payments_cannot_over_allocate_invoice`, `test_changed_snapshot_cannot_approve`, `test_concurrent_retries_return_the_same_committed_response`. | Managed-cloud transaction/role/locking compatibility and backup restoration need deployed evidence. Model output never performs approval. |
| Worker crash, lease loss or uncertain provider dispatch | Durable queue/lease fences, attempt reservations, stored-response recovery, uncertain-call stop. Job tests (previous repository: `../../tests/integration/test_jobs.py`): `test_expired_pre_call_lease_is_recovered_and_fences_old_worker`, `test_reserved_unknown_call_stops_recovery_and_retains_budget`, `test_committed_provider_response_reused_after_crash_without_another_call`. | Cloud wake-up/outbox, duplicate SQS delivery and cold database resume remain unimplemented/unverified. Local polling is not proof of scale-to-zero operation. |
| Malicious or oversized PDF/CSV; parser exhaustion | Supported formats only, strict exact CSV money, file/page/text limits, bounded credential-free parser process, no external resource fetch. Intake tests (previous repository: `../../tests/unit/test_intake.py`): `test_pdf_rejects_scans_encryption_actions_and_page_overflow`, `test_wall_deadline_kills_and_reaps_actual_child`, `test_pdf_text_and_decoded_stream_limits`. | The process is not an OS sandbox; native parser vulnerabilities and new formats remain risks. Cloud resource/isolation limits need verification. No OCR or arbitrary document support claimed. |
| Evidence-object substitution or traversal | Server-owned immutable locator/version/hash, workspace scoping and link rejection. Object tests (previous repository: `../../tests/unit/test_intake.py`): `test_immutable_object_atomic_deduplication_tamper_and_workspace_scope`, `test_object_store_rejects_symlink_directory_and_version`; original checks (previous repository: `../../tests/integration/test_intake.py`): `test_tampered_original_prevents_acceptance`. | S3 immutability, IAM/TLS and object/database restore are future adapter/operation evidence. Local filesystem checks do not verify S3. |
| Browser injection, attacker URLs or hostile model text | Literal-text escaping; warning text/categories are fixed and source links are bound to the case. Frontend security tests (previous repository: `../../frontend/tests/security.test.mjs`); format tests (previous repository: `../../frontend/tests/format.test.mjs`); recorded-contract checks (previous repository: `../../frontend/tests/recorded.test.mjs`). | Complete visual/accessibility/public inventory review remains separate. Future rich text or external link rendering needs new checks. No raw attacker payload is copied into a warning. |
| Credential/evidence leakage through logs, traces, errors or public bundles | Allowlisted event fields, finite labels, no evidence/prompts/responses in routine telemetry, sanitized child logs and strict public exports. Telemetry tests (previous repository: `../../tests/unit/test_observability.py`): `test_untrusted_fields_codes_and_exception_text_never_enter_any_telemetry`, `test_subprocess_log_resanitization_preserves_correlation_and_discards_payloads`; demo export tests (previous repository: `../../tests/unit/test_demo_export.py`). | Protected correlation identifiers still require access/retention controls. Cloud sinks, secrets and actual notification delivery are unverified. Unknown token/cost data must not be reported as zero. |
| Caller-supplied identity, expired membership or exposed development API | Loopback-only configured principal, origin/host/body checks and current database membership. HTTP tests (previous repository: `../../tests/integration/test_web_api.py`): `test_actor_is_never_taken_from_request`, `test_unauthorised_scope_and_revoked_membership`, `test_platform_environment_cannot_enable_development_identity`. | This is a local access boundary, not cloud authentication. Select and verify trusted owner authentication and environment separation before exposure. Never disable fail-closed startup to deploy. |
| Unbounded inference or duplicate charge after failure | Per-attempt and job reservations, bounded calls/time, single concurrency, timeout/uncertain-call stop and no automatic provider replay. Store tests (previous repository: `../../tests/integration/test_investigation_store.py`): `test_budget_reservations_survive_timeouts_and_concurrent_requests`, `test_call_count_limit_cannot_be_reset_by_zero_reported_usage`; evaluation opt-in (previous repository: `../../tests/integration/test_evaluation.py`): `test_live_opt_in_rejected_before_database_or_files`. | Per-run reservation is not a deployment-wide bill cap. Provider retries, tokens, pricing, quotas and cloud inference-disable controls must be bounded and observed separately. |
| Test-answer leakage, missing failures or chosen-best results | Separate source/scorer processes, source allowlist/hash seals, strict trial-bound reviews and all-scheduled denominators. Evaluation contracts (previous repository: `../../tests/unit/test_evaluation_contracts.py`): `test_family_cannot_span_splits`, `test_worker_label_guard_is_real_subprocess_boundary`, `test_no_best_of_or_duplicate_schedule`; scoring tests (previous repository: `../../tests/unit/test_evaluation_scoring.py`): `test_provider_failures_stay_in_overall_denominator`. | Python guards are not OS security boundaries. Public labels can be inspected; new final sources must be structurally separate and retired after tuning. New variants/metrics require new regression checks. |

## Cloud exposure gates

Cloud identity, environment/IAM/database separation, private S3 evidence, supported provider service credentials, durable wake-up/outbox, inference disable/limit controls, deployed redaction, alert delivery, rollback and actual database/object restore remain open. AWS design gates (previous repository: `aws-deployment.md`) and release evidence (previous repository: `../release-readiness.md`) define the deployment milestone. Local Lambda-image/PostgreSQL probes do not verify AWS identity, Aurora networking or live operation. The recorded public build has no live service connection.

Use the same negative tests against the deployed adapters, including membership revocation after waiting for a lock, foreign object/job identifiers, expiry/replay, denied approval by worker identity, collector failure and provider uncertainty. Record actual timestamps, image/configuration identities, service logs/metrics, costs and remaining gaps per environment. Security/financial violations block exposure regardless of quality or speed.
