# Security

This is an early product foundation. No hosted financial application or tax-correctness guarantee is available. Review [the threat model](docs/security/threat-model.md) before adding evidence, tools or network access.

Do not put private taxpayer data, secrets, sessions, prompts or traces in an issue or public pull request. Use a private channel agreed with the owner for a sensitive report; a dedicated reporting channel is not configured yet.

Dependency and skill changes require a pinned source, licence review and inspection of executable or instruction-bearing content. The known hacienda-cli licence and hardening concerns remain adoption blockers in the research inventory.
